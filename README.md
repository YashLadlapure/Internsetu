# InternSetu

A full-stack internship management platform built by **Yash Ladlapure**.

## Overview

InternSetu is a comprehensive internship management system that connects students, teachers, placement cells, and recruiters — streamlining the entire internship lifecycle from posting to placement.

## Tech Stack

- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, Redux Toolkit
- **Backend**: Spring Boot, Java, PostgreSQL, Spring Security, JWT
